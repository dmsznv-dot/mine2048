# ⛏ МАЙН2048: Шахтёрский Крафт (Mine2048)

Браузерная головоломка в жанре **2048** в сеттинге блоков и руд **Minecraft**, разработанная как автономный веб-прототип под платформу **Яндекс Игры** (Desktop & Mobile WebView).

Одинаковые блоки на соседних клетках визуально **стыкуются друг с другом** цветным пиксельным швом и при свайпе сливаются в более редкую породу — от обычной земли и булыжника до алмазов, изумрудов, древних обломков незерита и маяка Звезды Незера.

## ⚙️ Ключевые механики и особенности

- **Визуальная стыковка соседних блоков:** когда два одинаковых блока стоят рядом по горизонтали или вертикали, между ними появляется яркая перемычка цвета соответствующей руды, подсказывающая доступное слияние.
- **Система опыта шахтёра (`XP`) и уровней:** каждое слияние приносит очки опыта и рассыпает пиксельные осколки породы вместе со сферами `XP`. За каждый новый уровень игрок получает дополнительные заряды инструментов.
- **Шахтёрские инструменты:**
  - **⛏ Кирка** — активирует режим добычи: клик по любому мешающему блоку на поле разбивает его в осколки.
  - **↩ Отмена хода** — возвращает состояние поля на шаг назад.
- **Процедурный звук (`Web Audio API`):** синтезированный звук шага по камню, хруст породы при раскопке и фирменный перезвон сфер опыта без внешних аудиофайлов.
- **Готовность к платформе Яндекс Игры:**
  - Отключены контекстное меню правого клика, выделение текста и перетаскивание элементов.
  - Блокировка системного скролла/зума страницы при свайпах на мобильных экранах (`touch-action: none`, `passive: false`).
  - Автоматическое приглушение звука при сворачивании вкладки или приложения (`visibilitychange`).
  - Сохранение рекорда и открытой коллекции руд в `localStorage`.

## 🎮 Управление

- **ПК / Клавиатура:** клавиши `W`, `A`, `S`, `D` или стрелки `↑`, `←`, `↓`, `→` (а также перетаскивание мышью).
- **Смартфоны и планшеты:** свайпы пальцем в любом направлении по игровому полю.

## 🚀 Быстрый запуск локально

Проект не требует сборщиков и внешних зависимостей. Достаточно открыть `index.html` в браузере или запустить локальный сервер:

```bash
git clone https://github.com/dmsznv-dot/mine2048.git
cd mine2048
python3 -m http.server 8088
```

После запуска откройте в браузере: `http://localhost:8088`
